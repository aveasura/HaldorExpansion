# Haldor Expansion

[English](README.md) | [Русский](README.ru.md)

Мод для Valheim на BepInEx + Jotunn, который расширяет торговлю у Haldor: добавляет настраиваемый ассортимент, продажу трофеев и cores, требования по прогрессу мира и уникальные предметы с кастомными боевыми механиками.

## Установка для игроков

Для обычной установки не нужно менять код, настраивать `.csproj`, создавать `HaldorExpansion.Local.props` или отдельно копировать PNG-файлы.

Достаточно положить скомпилированный файл:

```text
HaldorExpansion.dll
```

в папку плагина:

```text
BepInEx/plugins/aveasura-HaldorExpansion/
```

Игровые иконки предметов уже встроены внутрь `HaldorExpansion.dll` как embedded resources.

> `HaldorExpansion.Local.props` нужен только разработчикам для локальной сборки проекта. Игрокам он не нужен.

## Важно для multiplayer / dedicated server

Мод меняет геймплей и добавляет сетевые механики, поэтому на dedicated server его должны иметь и сервер, и все клиенты.

Рекомендуется использовать одинаковую версию мода на сервере и у всех игроков.

Цены товаров, требования по прогрессу мира, цены продажи трофеев и cores синхронизируются с сервера. При подключении к dedicated server серверный конфиг является главным.

## Что добавляет

- новые уникальные товары у Haldor;
- дополнительные ресурсы и материалы для крафта у Haldor;
- настраиваемые цены для всех товаров, добавленных модом;
- настраиваемые требования `RequiredGlobalKey` для каждого товара;
- настраиваемые цены продажи трофеев;
- настраиваемые цены продажи `SurtlingCore`, `BlackCore` и `MoltenCore`;
- продажу трофеев, включая трофеи Deep North;
- fallback-цену для трофеев, которые не перечислены явно;
- уникальные предметы с кастомными боевыми механиками;
- кастомные броню и плащи с рискованными эффектами;
- активную способность для кастетов Bone Crushers;
- серверную синхронизацию настроек магазина и цен продажи;
- поддержку multiplayer / dedicated server через `NetworkCompatibility(EveryoneMustHaveMod, Minor)`;
- русскую и английскую локализации для добавленных предметов и эффектов.

## Конфигурация

Файл конфигурации создаётся автоматически после запуска мода.

### Цены товаров у Haldor

У каждого товара, добавленного модом в магазин Haldor, есть отдельная настраиваемая цена.

Пример:

```ini
Grit Cestus Price = 2500
Iron Price = 225
Silver Price = 550
```

В multiplayer эти значения синхронизируются с сервера.

### Требования по прогрессу мира

Для каждого товара можно указать Valheim world global key, который должен быть открыт до появления предмета у Haldor.

Пример:

```ini
Grit Cestus RequiredGlobalKey = defeated_bonemass
Silver RequiredGlobalKey = defeated_gdking
```

Оставьте значение пустым, чтобы предмет был доступен без ограничения:

```ini
Grit Cestus RequiredGlobalKey =
```

Основные ключи боссов:

```text
defeated_eikthyr     - Eikthyr
defeated_gdking      - The Elder
defeated_bonemass    - Bonemass
defeated_dragon      - Moder
defeated_goblinking  - Yagluth
defeated_queen       - The Queen
defeated_fader       - Fader
defeated_frozenking  - Kall Fimbulbringer
```

### Цены продажи трофеев и cores

Для поддерживаемых трофеев можно независимо настроить цену продажи Haldor.

Пример:

```ini
Eikthyr Trophy Price = 70
Bonemass Trophy Price = 150
Fader Trophy Price = 1000
```

Значение `0` отключает продажу конкретного трофея.

Также есть fallback-настройка для трофеев, которые не перечислены явно:

```ini
Unlisted Trophy Price = 10
```

Она позволяет продавать трофеи, добавленные другими модами или будущими обновлениями Valheim.

Для трёх дополнительных редких материалов также доступны отдельные цены:

```ini
Surtling Core Price = 50
Black Core Price = 100
Molten Core Price = 150
```

Значение `0` отключает продажу соответствующего предмета.

### Кнопка способности Cestus

Активная способность Bone Crushers по умолчанию вызывается средней кнопкой мыши:

```ini
Ability Key = Mouse2
```

Основные обозначения кнопок мыши:

```text
Mouse0 = левая кнопка мыши
Mouse1 = правая кнопка мыши
Mouse2 = средняя кнопка мыши
```

Также можно использовать другие значения Unity `KeyCode`.

### Синхронизация в multiplayer

Цены товаров, требования по прогрессу, цены трофеев и cores синхронизируются с сервера.

На dedicated server серверный конфиг является главным. Если локальные значения клиента отличаются, во время подключения используются значения сервера. Локальный файл конфигурации клиента при этом не перезаписывается навсегда.

## Рекомендуемый стиль игры

Мод лучше всего раскрывается на повышенной сложности, где дополнительные предметы ощущаются не как бесплатное усиление, а как рискованные инструменты выживания.

Для более хардкорного прохождения хорошо сочетается с:

- `Smoothbrain-CreatureLevelAndLootControl` - усиление существ;
- `warpalicious-Monster_Modifiers` - дополнительные модификаторы существ;
- `ASharpPen-Custom_Raids` - более опасные и частые рейды.

Эти моды не являются обязательными зависимостями.

## Runtime assets

Игровые иконки предметов находятся внутри `HaldorExpansion.dll` как embedded resources.

Игрокам не нужно отдельно копировать PNG-файлы.

Исходные PNG-файлы лежат в проекте в папке:

```text
HaldorExpansion/Assets/Icons/
```

Они нужны только для сборки проекта из исходников.

## Требования для разработки

- Valheim;
- BepInEx 5;
- Jotunn;
- .NET Framework 4.8;
- Visual Studio или Rider.

Проект использует локальные пути к Valheim/r2modman DLL в `HaldorExpansion/HaldorExpansion.csproj`. Пути вынесены в MSBuild-свойства:

- `R2ModmanProfileDir`;
- `ValheimInstallDir`;
- `ValheimDedicatedServerDir`;
- `ClientPluginDeployDir`;
- `ServerPluginDeployDir`.

Если папки отличаются, используйте `HaldorExpansion.Local.props`, как описано ниже в разделе Local build paths.

## Local build paths

Если пути к Valheim, r2modman или dedicated server отличаются от дефолтных в `.csproj`, создайте локальный файл настроек:

```text
HaldorExpansion/HaldorExpansion.Local.props
```

Для этого можно скопировать готовый пример:

```text
HaldorExpansion/HaldorExpansion.Local.props.example
```

и переименовать копию в:

```text
HaldorExpansion/HaldorExpansion.Local.props
```

После этого поменяйте пути внутри `HaldorExpansion.Local.props` под себя.

`HaldorExpansion.Local.props` не должен попадать в Git, потому что содержит локальные пути конкретной машины.
